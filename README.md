# Java Backend Portfolio

Repositório dedicado ao desenvolvimento de projetos práticos utilizando Java, com foco em programação backend, lógica de programação e Programação Orientada a Objetos (POO).

## Objetivo

Consolidar conhecimentos em desenvolvimento backend por meio da construção de sistemas práticos, evoluindo gradualmente em organização de código, estruturas de dados, orientação a objetos, bancos de dados e desenvolvimento de APIs.

## Projetos

### 01 — Sistema de Cadastro de Pessoas

Sistema de cadastro desenvolvido em Java, executado pelo terminal.

**Funcionalidades:**
- Cadastro de pessoas;
- Validação de dados;
- Listagem de registros;
- Tratamento de entradas inválidas.

**Conceitos praticados:** classes, objetos, construtores, ArrayList, estruturas de repetição e tratamento de exceções.
