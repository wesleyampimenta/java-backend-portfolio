# Sistema de Cadastro de Pessoas

Projeto desenvolvido em Java com o objetivo de praticar os fundamentos da linguagem e os conceitos iniciais de Programação Orientada a Objetos (POO).

## Funcionalidades

- Cadastro de pessoas;
- Validação de nomes e idades;
- Tratamento de entradas inválidas;
- Listagem de pessoas cadastradas;
- Numeração dos registros;
- Menu interativo pelo terminal.

## Tecnologias utilizadas

- Java
- ArrayList
- Scanner
- Try/Catch
- Programação Orientada a Objetos (POO)

## Estrutura do projeto

```text
01-sistema-cadastro/
├── Main.java
├── Pessoa.java
└── README.md
```

## Como executar

1. Abra o terminal dentro da pasta do projeto.
2. Compile os arquivos:

```bash
javac -encoding UTF-8 Main.java Pessoa.java
```

3. Execute:

```bash
java Main
```

## Conceitos praticados

- Variáveis e tipos de dados;
- Estruturas condicionais;
- Laços de repetição;
- Listas dinâmicas (`ArrayList`);
- Classes e objetos;
- Construtores;
- Validação de dados;
- Tratamento de exceções.

## Observação

Os dados cadastrados ficam armazenados em memória durante a execução do programa. Ao encerrá-lo, os registros são perdidos.
